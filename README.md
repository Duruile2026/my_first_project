## 任务三：通用素养
### 1. 分支与合并
- **分支（Branch）**：就像在主线任务里开了一个平行世界，你可以在里面随便改代码，不会影响正在运行的主线。
- **合并（Merge）**：当平行世界里的功能测试好了，把它拉回主线，这就是合并。
### 2. 命令行用途
- `cd`：切换当前所在的文件夹。
- `ls`：列出当前文件夹里有哪些文件。
- `mkdir`：新建一个文件夹。
- `git add`：把修改的文件放入准备提交的暂存区。
- `git commit`：把暂存区的内容拍一张快照，记录到版本历史里。
- `git push`：把本地的提交推送到 GitHub 远程仓库。
### 3. 信息与安全意识
- **LICENSE**：我选择了 MIT 许可证。因为它最宽松，允许别人自由使用、修改和分发我的代码，只要保留我的版权声明即可，非常适合这个学习项目。
- **两步验证**：已开启 GitHub 两步验证。
- **AI 错误信息记录**：
  - AI 曾告诉我：*“在 HTML 中，直接用 `font-family: Arial` 就能在所有电脑上显示出完全一致的字体。”*
  - 我查证后发现：这是**错误**的。不同操作系统（Windows / macOS / Linux）对字体的渲染和默认字体库不同，如果用户电脑没装 Arial，浏览器会回退到默认字体。为了保证一致，通常需要提供多个备选字体（如 `font-family: Arial, Helvetica, sans-serif;`）甚至使用 Web Font。
